# 그날의 사정

**SillyTavern용 ABO 세계관 설정·상태 추적 확장**

캐릭터(CHAR)와 사용자 페르소나(USER)에 ABO 설정을 적용하고, 역할극 중 발생하는 사건을 바탕으로 주기, 컨디션, 페로몬, 각인, 취향, 임신 및 서사 시간을 관리합니다. 기존 캐릭터 카드를 수정하지 않고 채팅별로 사용할 수 있으며,

[English Guide](README_EN.md)

## 설치 방법

1. SillyTavern에서 **확장 관리**를 엽니다.
2. **확장 설치** 기능에 배포자가 안내한 GitHub 저장소 주소를 입력해 설치합니다.
3. 설치 후 SillyTavern을 새로고침합니다.
4. 확장(마술봉) 메뉴에서 **그날의 사정**을 엽니다.

기존 설치를 업데이트하는 경우 확장 관리에서 업데이트한 뒤 새로고침하세요. 기존 채팅을 장기간 사용했다면 업데이트 전에 데이터를 백업하는 것을 권장합니다.

### 동봉된 월드 인포

배포 파일에는 `worldinfo/[WI]Geunalui_Sajeong_v1.0.0.json`과 같은 이름의 규칙 문서가 들어 있습니다. 확장의 초기 분석·상태 추적 기능을 사용하기 위해 JSON을 별도로 가져올 필요는 없습니다. SillyTavern 월드 인포 항목으로 직접 활용하려는 경우에만 JSON을 가져와 활성화하세요.

같은 규칙의 월드 인포가 이미 활성화되어 있다면 중복 적용하지 않도록 확인하세요.

## 주요 기능

- **초기 설정·성향 분석:** CHAR와 USER의 카드·페르소나 설정을 바탕으로 ABO 속성과 성향 후보를 제안합니다. 제안은 선택·수정할 수 있습니다. 초기 프로필 설정에서 수동 고정 항목을 개별 해제하거나 CHAR·USER 프로필을 초기화할 수 있으며, RP 사건 기록은 보존됩니다.
- **상태 추적:** 인물별 컨디션과 페로몬 발산량을 기록하고, 확인된 서사 사건에 따른 변화를 반영합니다.
- **생리 주기:** 히트·러트·월경의 단계와 다음 주기까지 남은 서사 시간을 관리합니다. 도입부에 현재 월경 중이라고 명시된 경우 해당 상태를 반영하며, 주기 탭에서 월경 시작·종료를 직접 기록할 수 있습니다.
- **약물·임신:** 가상 세계관의 억제제, 유도제, 피임, 임신 가능 사건과 상태를 추적합니다. 임신 정보는 숨김 설정을 사용할 수 있습니다.
- **각인·관계:** 각인 관계와 효과, 분리 스트레스 및 관계 변화 사건을 관리합니다. 각인 규칙은 설정에 따라 조절할 수 있습니다.
- **취향·장면:** 선호·비선호·경계 등 취향을 관리합니다. 현재 장면은 CHAR 중심으로 표시하며, 확인된 USER 장면 정보는 별도로 확인할 수 있습니다.
- **기존 채팅 재분석:** 과거 대화에서 사건과 시간 경과를 다시 분석하고, 미리보기를 확인한 뒤 필요한 기록을 적용할 수 있습니다.
- **한국어 표시 후처리:** 영어 표현을 한국어로 정리하거나 자연스러운 한국어로 다듬는 처리 방식을 선택할 수 있습니다.
- **NPC 관리:** 추적할 NPC를 지정해 인물별 기록을 관리할 수 있습니다.

## 기본 사용 순서

1. 역할극에 사용할 채팅을 열고 **그날의 사정**을 실행합니다.
2. CHAR·USER 또는 추적할 NPC를 확인하고 ABO 설정을 지정합니다.
3. 초기 분석 결과를 검토해 필요한 후보만 선택·수정하여 적용합니다.
4. 역할극을 진행하면서 상태·주기·취향·장면 기록을 확인합니다. 이미 시작된 월경을 끝내거나 새로운 월경을 기록하려면 **주기** 탭의 시작·종료 기록을 사용하세요.
5. 이미 진행한 채팅이라면 **기존 채팅 상태 재분석**이나 시간 동기화를 이용할 수 있습니다.

## 이용 시 참고 사항

- AI 분석, 과거 채팅 재분석 및 선택형 한국어 후처리에는 사용 중인 모델·API에 따라 추가 호출이나 비용이 발생할 수 있습니다.
- AI가 추출한 사건이나 성향은 잘못 해석될 수 있으므로 적용 전 내용을 확인하세요.
- USER의 행동은 USER가 직접 작성한 근거 없이 캐릭터의 서술만으로 확정하지 않습니다. 이에 따라 USER 장면 기록이 표시되지 않을 수 있습니다.
- 서사 시간은 메시지 개수만으로 자동 추정하지 않습니다. 시간 경과가 모호하면 수동 확인이 필요할 수 있습니다.
- 약물·생식·임신 관련 규칙과 수치는 **허구의 ABO 세계관용 시뮬레이션**이며 현실의 의학적 지침이 아닙니다.
